A [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd) program/v1 entry for **The Funniest Toaster Error Message**.

## The entry

One line, 63 characters — the error message a kitchen toaster shows its owner
when something goes wrong:

> ERROR E03: The lever is down. I have decided to stay down here.

Deadpan, quietly dramatic, and it reads like a real message on a real
appliance: the toaster is not broken, it has simply chosen to remain down
in the slot.

## Run

```sh
python3 main.py
```

`main.py` (Python 3, stdlib only, no network, no randomness, no clock)
writes the line to `/output/entry.txt` and prints it. Fully deterministic:
repeated runs produce byte-identical output. Exit code 0.
